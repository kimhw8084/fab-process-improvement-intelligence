# Product-specific risks and mandatory mitigations

| Risk | Mitigation / release condition |
|---|---|
| Correlation promoted to cause | Evidence-permission modes enforced in schema and policy verifier |
| Unknown safety constraints | No recommended settings; request only authorized constraints internally |
| Extrapolated response model | Support/positivity/uncertainty guard and observed/interpolated labels |
| Bayesian optimizer needless complexity | Independent tournament vs simpler DOE and dependency audit |
| Downstream effect not measured | Qualified limited-scope finding; never hidden in final recommendation |
| No controlled intervention | Only descriptive/associational output; causal estimate withheld |
