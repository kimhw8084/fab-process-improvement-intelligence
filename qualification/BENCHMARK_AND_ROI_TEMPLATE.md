# FAB Process Improvement Intelligence — precommitted benchmark and ROI workplan

- Define simple existing-tool/human analysis baseline and task mix prior to holdout runs; measure real work, not imagined savings.
- Synthetic scenarios: include 13,000-schema source search plus small dense golden wafer/lot/step/metrology histories; enrich scenario-specific 12 challenge cases from `critical_cases.json` and at least 100 fixed seeded cases before claiming broad accuracy.
- Report p50/p95 elapsed time, memory, tool/model calls, false accepted joins, refused invalid analysis, validated task success, human review burden, real baseline comparison and source evidence.
- Scientific expected values must come from independent fixtures/human-reviewed methods, not the model under evaluation.
- Perform actual engineering user study after internal qualification; measure eligible users/workflows, manual vs assisted verified completion, review/correction, adoption, maintenance and TCO separately.
- Do not set an invented absolute Samsung seconds-saved or yield increase target; derive thresholds from measured baseline and pre-register them.
